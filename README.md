# Habit Tracker Backend

Backend API для мобільного застосунку Habit Tracker з гейміфікацією та 3D героями.

## Опис

Цей проект є backend API для застосунку відстеження звичок з елементами гейміфікації. Користувачі можуть створювати звички, відстежувати їх виконання та отримувати нагороди за досягнення.

## Функціонал

- 🔐 Аутентифікація користувачів
- 📝 Управління звичками (CRUD)
- 📊 Статистика виконання
- 🎮 Гейміфікація (XP, рівні, досягнення)
- 🌍 Мультимовність (en, uk, de, fr, es)
- 📱 API для мобільного застосунку

## Технології

- PHP 8.4
- Laravel 12
- MySQL
- Redis
- Docker
- Nginx
